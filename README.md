# Personal agent setup

Shared agent instructions and skills, maintained in `~/.agents`.

- `AGENTS.md`: personal working preferences.
- `skills/`: installed and custom agent skills, including browser/desktop automation and Pi/Rex workflows.
- `.skill-lock.json`: source metadata for skills managed by the skill installer.
- `THIRD_PARTY_NOTICES.md`: upstream attribution and license notices for bundled third-party skills.

Pi extensions, themes, and sanitized configuration examples live separately in [pi-setup](https://github.com/urjitc/pi-setup).

This is a personal setup, not a universal default. Review instructions and scripts before using them. Synced skills under `skills/synced/` are ignored and not included. Never commit credentials, live authentication configuration, or session transcripts.

No repository-wide redistribution license is selected; third-party files retain their upstream licensing.
